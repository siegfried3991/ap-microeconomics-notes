# MicroQuest English Literature

Original close-reading course: 4 units, 12 lessons, 72 questions, 6 passages, 20 retrieval cards, and 6 self-reviewed writing tasks. `data.js` contains public original teaching content, `ui.js` contains the studio and bounded literature-state cleaner, and `style.css` preserves MicroQuest’s interface with a warm paper reading surface.

Lessons move from literal reading to inference, language/effect analysis, character and thematic tensions, then thesis/evidence/commentary and unseen writing. The initial assessment format and October benchmark are distinguished. The benchmark simulation is original transfer practice, not an actual or forecast school test. All original passages are explicitly credited as MicroQuest material, not Steinbeck quotations.

Classroom sources were consulted privately; none is reproduced here. The shared-files listing failed to load, so the course does not claim a complete syllabus survey. Full source/coverage notes are available inside the studio.

Integrates through the shared course catalog and checkpoint version 7; module identifiers are stable. Written work is escaped and bounded, timers pause on checkpoint restoration, and no written task is automatically graded. Free-text responses and annotations remain in the learner’s existing private account checkpoint or local guest storage. No AI connection is required.
